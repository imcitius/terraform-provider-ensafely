# ensafely_platform_regions_available (Data Source)

Lists the Platform probe regions that can be selected in
[`ensafely_platform_regions`](../resources/platform_regions.md), and how many
the Tenant's Plan allows.

## Example usage

```terraform
data "ensafely_platform_regions_available" "all" {}

output "selectable_regions" {
  value = data.ensafely_platform_regions_available.all.names
}

output "region_limit" {
  # -1 is unlimited.
  value = data.ensafely_platform_regions_available.all.limit
}
```

### Read-Only

- `limit` (Number) How many regions the Tenant's plan allows: `-1` is unlimited, `0` means the plan has no Platform regions.
