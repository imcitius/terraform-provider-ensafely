# ensafely_check (Data Source)

Reads one Check by UUID. It has the same attributes as the
[`ensafely_check` resource](../resources/check.md), all read-only, plus `type`.
Secrets are not readable. Inheritable settings that the check leaves to the
Tenant's check defaults are null; the data source does not resolve effective
values.

For a type this provider version does not manage (for example `pgsql_replication`), `type`
and the common attributes are set and every type attribute is null.

## Example usage

```terraform
data "ensafely_check" "api" {
  id = "123e4567-e89b-12d3-a456-426614174000"
}

output "api_interval" {
  value = data.ensafely_check.api.interval
}
```
