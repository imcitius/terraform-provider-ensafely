# ensafely_platform_regions (Resource)

Manages the Platform probe regions selected for the Tenant: the
Ensafely-operated regions its `saas_only` and `multi_region` Checks run in.
There is one per Tenant. Creating the resource replaces the current selection.

The Plan limits how many regions can be selected: Free 2, Pro 5, Enterprise
unlimited. Selecting more fails at apply with an `Ensafely plan limit reached`
error that names the limit and the selected regions; a region that does not
exist fails with `Unknown platform region`. List the selectable regions and
the limit with the
[`ensafely_platform_regions_available`](../data-sources/platform_regions_available.md)
data source.

Requires Terraform 1.11+ (or OpenTofu 1.11+). Applying changes needs a Tenant
API key with the `api_write` scope; `api_read` is enough for `terraform plan`.

## Example usage

```terraform
# Run the Tenant's platform Checks from two regions (the Free plan allows two).
resource "ensafely_platform_regions" "current" {
  regions = ["eu-paris", "us-washington"]
}
```

## Schema

### Required

- `regions` (Set of String) Selected region names, for example `["eu-paris", "us-washington"]`. An empty set selects no Platform regions (Checks then run only on the Tenant's own Probes).

### Read-Only

- `id` (String) Always `current`.

## Destroy

Destroy resets the selection to the **Plan's default regions**
(`DELETE /api/platform-regions`), not to an empty selection: the Plan's
defaults that a Probe currently serves, capped at the Plan's limit. This is
the selection a new Tenant on the same Plan starts with.

## Import

```shell
terraform import ensafely_platform_regions.current current
```

The import ID is always `current`.
